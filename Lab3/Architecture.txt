## По сути у вас есть набор вариантов, как это всё реализовать.

1) Сделать большой набор массивов:
  1) Продукты
  2) Покупатели
  3) Цены продуктов (причём номер элемента в массиве цен должен совпадать с массивом продуктов, для корректной работы
  4) Тележка покупателя (N таких массивов)
  5) Возможно склад? Некоторые ребята заморачивались со складом, но это feature.

2) Либо воспользоваться паттерном ключ => значение. Где ключ - это например название продукта, а цена - значение.
**Преимущество такого подхода в том, что вам не придётся создавать лишние массивы и путаться в логике**

3) Объединение паттернов
4) Придумать что-то своё


Ключ-значение, пример:

$products = [
    "Хлеб" => 50,
    "Молоко" => 80,
    "Сыр" => 250,
    "Вода" => 40
];


---

Формат в виде DB

```
// Имитация таблиц в оперативной памяти или сессии
$database = [
    'users' => [
        1 => ['id' => 1, 'name' => 'Иван'],
        2 => ['id' => 2, 'name' => 'Мария']
    ],
    
    'products' => [
        101 => ['id' => 101, 'title' => 'Смартфон', 'price' => 50000],
        102 => ['id' => 102, 'title' => 'Чехол для телефона', 'price' => 1500],
        103 => ['id' => 103, 'title' => 'Наушники', 'price' => 12000]
    ],
    
    // Склады: ключ — id товара, значение — массив с остатками по складам
    'stocks' => [
        101 => ['sklad_moscow' => 5, 'sklad_spb' => 2],  // Итого 7 штук
        102 => ['sklad_moscow' => 0, 'sklad_spb' => 15], // Итого 15 штук
        103 => ['sklad_moscow' => 0, 'sklad_spb' => 0]   // Нет в наличии
    ],
    
    // Корзины: ключ — id пользователя, значение — массив добавленных товаров
    'carts' => [
        1 => [ // Корзина пользователя с id = 1
            101 => ['quantity' => 1, 'price_at_added' => 50000],
            102 => ['quantity' => 2, 'price_at_added' => 1500]
        ],
        2 => [ // Корзина пользователя с id = 2 (пока пустая)
        ]
    ]
];
```
